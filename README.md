# Proyecto Final - Sistemas Operativos y Redes

## 📋 Descripción del Proyecto
Este repositorio contiene la configuración, infraestructura y código fuente para el despliegue de un servidor web basado en **Linux (Ubuntu Server)** en un entorno de **Servidor Privado Virtual (VPS)**.

El proyecto aloja tres páginas web independientes gestionadas mediante **Virtual Hosts de Apache** y cuenta con monitoreo activo de red implementado a través de **Zabbix**.
